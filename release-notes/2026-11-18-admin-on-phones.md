# Admin console works on phones (18 Nov 2026)

- **Report review on phones:** tapping a report now opens it full screen. Before, it opened underneath
  the whole list of reports, so it looked like nothing happened. The phone's back button closes it.
- **Bottom bar on phones:** Home, Reports (with the open count), Members, Rooms and More (the full menu).
- **Tables become cards** on phones, with each value labelled, so no sideways scrolling.
- **Confirmation windows** (suspend, ban, remove…) slide up from the bottom and always fit the screen.
- **Chatroom Remove / Ban buttons** are always shown on touch screens (they only appeared on mouse hover).
- Typing boxes no longer make the phone zoom in.
- Admin website only; no database changes. The computer layout is unchanged.
