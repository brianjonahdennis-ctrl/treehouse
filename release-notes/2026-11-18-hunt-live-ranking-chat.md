# Live ranking and a chat for every Treasure Hunt

During a hunt, players can see everyone's nickname, their place and how many checkpoints they've passed, for example 3/5.
Each hunt has a set number of winners. When they've all finished, everyone still playing is told and can keep going or quit.
Everyone who registers is added to the hunt's own chat, named after the hunt, with the rules pinned at the top.
Ask the treehouse team questions there. Nobody can see who else is in the chat, and it is deleted when the hunt ends.
