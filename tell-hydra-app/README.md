# treehouse (formerly Tell Hydra) — Android and iOS app

A Capacitor app that opens the member app at **https://treehouse.ng/home** (Home · Inbox · Discover · Matches · Profile) in a full-screen app window. APK 1.0 and 1.1 open /link, which now forwards to /home.
Because it loads the live site, new website features show up in the app **without a new APK**.
Rebuild only when the app shell changes (name, icon, splash, version, native features).

- App id: `com.brianjonahdennis.tellhydra` · name: **Tell Hydra**
- Opens: `server.url` in `capacitor.config.json` · offline page: `www/offline.html`
- Icons and splash: generated by `node tools/make-icons.js` (same artwork as the website icon)

## Build the APK

Tools are installed in `~/.local` (no Android Studio needed):

```bash
export JAVA_HOME=$(ls -d ~/.local/jdk/jdk-21*/Contents/Home) ANDROID_HOME=~/.local/android-sdk
npx cap sync android
cd android && ./gradlew assembleRelease
# → android/app/build/outputs/apk/release/app-release.apk
```

Before each new release, raise `versionCode` (and `versionName`) in `android/app/build.gradle`,
otherwise phones won't install it as an update.

## Signing key — back it up

`signing/tell-hydra-release.jks` and `signing/keystore.properties` (its passwords) sign every
release. **Every future update must be signed with this exact key**, and the same key is needed to
publish on Google Play. If it's lost, existing installs can't be updated. Keep a copy somewhere
safe (e.g. a password manager or encrypted drive). Never share it or commit it.

## Known limits of this first version

- Email links (verification, password reset) open in the phone's browser, not the app.
- "Save image" and "Share" in the owner inbox use browser features that Android's app WebView
  doesn't fully support; the native Share and Filesystem plugins will fix this.
- No push notifications yet.

## Google Play later

Play requires an **App Bundle** (`./gradlew bundleRelease` → `.aab`), a privacy policy URL, the
content rating questionnaire (dating → 18+), and Data safety answers. In-app account deletion,
blocking and reporting are already in place.

## iOS

The iOS project is in `ios/` (Capacitor 8, Swift Package Manager: no CocoaPods needed). Same app id
(`com.brianjonahdennis.tellhydra`), name, icon and splash as Android; it opens `/home`.

Building needs **Xcode** (Mac App Store), then:

```bash
npx cap sync ios
npx cap open ios        # opens Xcode: pick an iPhone simulator and press Run
```

- Icon and splash: `node tools/make-icons.js` also writes the iOS ones (the icon has no alpha
  channel, which the App Store requires).
- Running on a real iPhone or publishing needs an Apple Developer account ($99/year): set the
  Team under Signing & Capabilities in Xcode.
